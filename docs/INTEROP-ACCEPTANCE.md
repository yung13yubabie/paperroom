# 三款筆記工具的互通驗收

依平常的操作分開驗收。每列標示的是該列寫明的範圍。資料格式、原廠服務和紙間本機操作各自驗證。完整功能背景另見 [逐項功能清冊](FEATURE-STATUS.md)。

| 想完成的工作 | Notion | Obsidian | Heptabase |
| --- | --- | --- | --- |
| 把頁面、欄位與附件搬進紙間 | [資料列和原始頁面](INTEROP-NOTION.md) | [Vault 與 Bases](INTEROP-OBSIDIAN.md) | [Markdown 及伴隨畫布](INTEROP-HEPTABASE.md) |
| 在本機修改和導覽 | [集合、批次欄位編輯和來源頁反查](INTEROP-NOTION.md#已實裝且驗證) | [動態檢視與 Canvas 卡片](INTEROP-OBSIDIAN.md#已實裝且驗證) | [筆記卡、跨白板複製和子白板](INTEROP-HEPTABASE.md#已實裝且驗證) |
| 檢查原廠備份或連線服務 | [原廠 ZIP、協作和發佈](INTEROP-NOTION.md#已實裝待真實來源) | [原廠設定、Sync 和 Publish](INTEROP-OBSIDIAN.md#未實裝) | [All-Data、Space 和分享](INTEROP-HEPTABASE.md#未實裝) |

- **已實裝且驗證**表示已從指定入口跑完所述流程。合成輸入、原廠實檔和實際原廠介面證據各以連結標出。Windows Server 驗收只覆蓋所列 Windows Server 情境。
- **已實裝待真實來源**表示已有可執行的匯入或資料層能力，但還需要同一操作情境的原廠真檔或可寫測試空間。
- **未實裝**表示紙間尚缺所述能力。合法保留來源可以讓日後補驗。
- **離線不可實現的雲端服務**指出功能依賴跨裝置伺服器、共同編輯連線或原廠帳戶。紙間可另有本機能力，其證據另列。

## 本機核心操作驗收

| 操作 | 通過條件 |
| --- | --- |
| 全域搜尋與來源定位 | 在同一搜尋視窗查找筆記及 PDF 標註。用兩篇同名筆記與兩個同名 PDF 核對來源、頁次與位置。搜尋不到或來源已失效時有清楚的狀態。重新開啟或還原後仍定位到同一來源。 |
| 完整備份與隔離還原 | 由應用程式匯出備份，再從檔案選單還原到新工作區。核對筆記、附件內容、白板引用與集合屬性；在還原副本修改後重開。取消、無效備份或已有目的地時保留原件與現有工作區。 |
| 既有工作流 | 同一筆記可從集合、筆記連結與白板往返。核對改名、版本還原、備份還原的資料身分。使用固定候選跑完整 Linux、Windows 測試及 Windows 原生介面案例。 |

## 原廠相容性待驗與功能缺口

| 來源 | 可結案的證據 |
| --- | --- |
| Notion Markdown 和 CSV | 在獲准的測試空間建立階層、附件與資料列，使用官方介面匯出 ZIP，再在紙間比對。只有原檔提供足夠身分與關聯資訊的情況，才能驗收關聯保真。 |
| Obsidian Canvas 和 Bases | 已驗案例參見 [Obsidian 功能對照](INTEROP-OBSIDIAN.md)。增加相容性聲明時，以官方應用產出的檔案核對對應節點、公式與檢視；未支援的公式、外掛或進階設定依功能列記錄。 |
| Heptabase | Markdown 和已列的伴隨畫布有對應入口。原廠 All-Data 還原尚未實裝，也缺獲准的原廠樣本。若要納入相容性，需取得隔離測試匯出、核對格式並實作後，測試附件、共用卡片與跨白板引用。 |

伺服器協作、原廠同步與帳戶服務依各產品清單另計。本機功能的驗收以表內操作為準。原廠相容性聲明以實測功能與格式為限。

## 什麼會阻擋正式發版

| 項目 | 放行所需證據 |
| --- | --- |
| 免安裝、離線的乾淨 Windows 10／11 | 從實際下載的候選套件取出 EXE，以兩個系統的標準帳戶斷網啟動，建檔、編輯、搜尋、備份還原、關閉再開。按 [GNU 候選斷網指引](../qa/windows-client-offline/GNU-CANDIDATE.md) 收集作業系統版本、實測結果與 EXE SHA-256。Windows Server 覆蓋範圍另列。 |
| 最終可散布封裝 | 核對本次固定來源、工具鏈、簽章狀態、兩次獨立建置、通知檔與實際下載內容。確認 ZIP 中的 EXE 與獨立 EXE 位元一致，依實際套件核對各元件的散布條件。GNU 與 MSVC 各看自己的連結與授權證據。 |
| 發行範圍與權限 | 固定版本的相容性聲明與本機工作流逐項對照已通過的證據，在授權涵蓋的候選與版本範圍內發行。 |

固定來源、下載 SHA-256 與實際驗收連結見 [草稿 PR #30](https://github.com/yung13yubabie/paperroom/pull/30)。
