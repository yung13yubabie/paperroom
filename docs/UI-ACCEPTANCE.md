# 功能入口與驗收紀錄

從[三款工具的公開功能盤點](FEATURES.md)和[紙間整合範圍](INTEGRATION-COVERAGE.md)可對照下表。所有實測使用合成資料。

與 Notion、Obsidian、Heptabase 逐項對照的結果見[功能狀態矩陣](FEATURE-STATUS.md)。

## 功能與操作

| 功能 | 紙間入口 | 驗收證據 |
| --- | --- | --- |
| 筆記、子頁、搜尋、連結 | 左側新增與搜尋、「連結」、檔案選單的 Markdown／Notion ZIP 匯入 | 早期 Wine 候選通過新增、中文搜尋及重開。分鏡樣本測試覆蓋同名筆記與明確路徑。 |
| Vault、每日筆記 | 「檔案 → 匯入 Obsidian Markdown 資料夾」、每日筆記 | Linux 測試驗證匯入、同名分流、標題定位及每日筆記。紙間介面完整操作待測。[分鏡樣本](../tests/fixtures/storyboard-zh/README.md) |
| 屬性、CSV、公式、關聯及彙總 | 「更多 → 設定／檢視文字屬性／筆記關聯」、「檔案 → 匯入 CSV 表格／資料集合與看板」 | 資料層覆蓋文字屬性、CSV、命名關聯、公式與備份。Astra 用無網卡 Wine 建立關聯，彙總 5+7 得到 12，將 7 改成 13 後得到 18。CSV 中的 URL 以文字保存。 |
| 集合看板 | 「檔案 → 資料集合與看板」→「看板操作」 | 同一次 Astra 介面測試移動卡片至「已完成」，關閉重開後仍保留。SQLite 完整性檢查回傳 `ok`。 |
| 多白板與分區 | 左下「卡片白板」→「白板操作」、卡片右鍵選單 | Linux 測試覆蓋白板分區、儲存及垃圾桶行為。拖曳與重開的 GUI 驗收待做。 |
| JSON Canvas | 「檔案 → 匯入 JSON Canvas／開啟已匯入的 Canvas」→拖曳節點，或從「Canvas 操作 → 編輯 Canvas」調整欄位 | 無網卡 Wine 匯入並核對未編輯檔案的逐位元匯出。從選單新增文字、檔案、連結與群組節點，調整位置、尺寸、堆疊和連線標籤，再匯出、重開、重匯出。獨立解析比對既有擴充欄位、節點順序與幾何。 |
| PDF 頁面及標註 | 「更多 → 附件與 PDF 摘錄 → 管理附件」→「開啟 PDF 頁面並標註」；拖曳頁面選區，填寫引文或註解。回跳可由附件管理「開啟已保存的 PDF 標註」或「PDF 操作 → 返回已保存的標註」進入。 | 無網卡 Wine 用實際滑鼠拖曳、儲存、換頁及重開。已比對來源頁像素、選區和 SQLite 中的正規化座標。備份與還原由資料層測試覆蓋。 |

## 複製筆記與 Notion 交接

| 流程 | 操作 |
| --- | --- |
| 複製單篇或使用中的分支 | 在原頁按「更多」→「複製筆記與內容」。選單篇或包含子頁，輸入同層未使用的名稱，再確認頁數與附件總量。副本會放在原頁旁。一次上限 128 頁、16 MiB 文字及屬性、64 MiB 附件，並沿用工作區附件總上限。 |
| 確認複製範圍 | 原稿不會被覆寫。若預覽後原稿、屬性、附件或子頁有變動，先重開複製預覽。紙間識別碼及已確立的舊標題連結仍指向原筆記。原本的來源身分、集合、白板配置和 PDF 標註需要從原頁查看。 |
| 交接 Notion 匯出資料 | 在「檔案」選「匯入 Notion Markdown ZIP」。可匯入合規的 Markdown 與 CSV 原檔。從批次下的「Notion 原始 CSV」開啟單份來源，再用「更多」→「附件與 PDF 摘錄」→「管理附件」→「儲存附件副本」。包內路徑可從同一附件選單查看。若要建立文字表格，再從「檔案」選「匯入 CSV 表格」。 |
| 核對關聯與附件 | Notion CSV 的關聯欄位可能只有網址，匯入至紙間後仍是文字。用 SQLite 工作區備份移到乾淨可攜目錄，核對 Markdown 子頁、附件內容和原始 CSV 的雜湊。[Notion 匯出說明](https://www.notion.com/help/export-your-content) · [Notion 關聯與彙總](https://www.notion.com/help/relations-and-rollups) |

## 書目、HTML 匯出與心智圖

| 流程 | 操作 |
| --- | --- |
| 匯入 Zotero 元資料 | 從 Zotero 匯出 CSL JSON。在「檔案」選「匯入 Zotero CSL JSON 書目」，核對預覽後確認。同名書目會建立個別子筆記。開啟批次根筆記，選「匯出 Zotero 原始 CSL JSON」可取得原檔。這個格式提供書目欄位，完整收藏庫、PDF、標註和 Word 引文連結需要其他方式保留。[Zotero 匯出說明](https://www.zotero.org/support/kb/exporting) |
| 在瀏覽器閱讀工作區 | 在「檔案」選「匯出工作區 HTML ZIP」，使用新檔名。解壓縮整包後開啟 `index.html`。可沿上層、本篇目錄、子筆記和有效的紙間整頁連結閱讀，並另存原始 Markdown 及附件。其他連結以文字呈現，完整目的地可在 Markdown 找到。匯出最多 10,000 篇、64 MiB Markdown 內文、128 MiB 附件。[Notion 工作區匯出參照](https://www.notion.com/help/export-your-content) |

### 長筆記大綱與離線目錄

1. 開啟一篇有 Markdown 標題的筆記，按 F8，依層級與行號選取段落。閱讀時會進入原文編輯定位。在前方新增標題或空行後，直接再按 F8，選單會以目前草稿計算。
2. 經「檔案 → 匯出工作區 HTML ZIP」輸出並整包解壓，從 `index.html` 開啟筆記。有標題的頁面可從「本篇目錄」跳到各小節。程式碼區塊中的 `#` 不會加入目錄，同名小節依篇內順序各自定位。
3. 原始 Markdown 可從同一頁的下載連結取得。回歸測試用繁中與 emoji 合成稿檢查 F8 選區、保存重開、還原後輸出的目錄目標及 Markdown 原文位元組。
| 建立心智圖 | 開啟卡片白板，從「白板操作」選「新增心智圖根節點」。右鍵選取節點後可加子節點、改名、改掛父節點或選取整個分支一起移動。有子節點時，請先調整分支再刪除父節點。從「匯出分支 JSON Canvas」可另存文字、位置和箭頭。要完整保留紙間可編輯的樹狀資料，請用工作區備份。[Heptabase 心智圖說明](https://wiki.heptabase.com/keyboard-shortcuts#mindmaps) |

測試時可先用同名的合成書目及父子筆記，匯出後把來源移出再重新開啟。比較原始 JSON、Markdown 和附件的 SHA-256。試著把心智圖父節點移到它的子節點下方，原有分支應保持原位。

## 同步區塊、Vault 嵌入與日誌月曆

用合成資料試操作即可。要試用既有工作區，先另存一份 SQLite 備份。

| 流程 | 操作 |
| --- | --- |
| 從兩篇筆記引用一段原文 | 在來源筆記的段落末尾加上半形空格和 `^sample-1`，存檔。開啟另一篇筆記，按 F6 選「插入同步區塊」，找來源筆記，再選區塊。紙間把標記加入這篇筆記末尾。在第三篇筆記再做一次。 |
| 從引用處修改原文 | 在引用筆記按 F6 選「管理本篇同步區塊」。依行號選一處，再選「編輯共用原文」。保存後其他引用在開啟時顯示新文字。若來源已被修改，保留輸入供複製，重新讀取來源再決定要改哪些內容。 |
| 查引用及解除同步 | 在來源按 F6 選「查看同步區塊引用」，選區塊後可開啟引用筆記。在引用筆記選「管理本篇同步區塊」，可開啟原文或只解除該行同步。內含連結、其他區塊 ID 或嵌入的原文需要手動複製，以保留原有定位。 |
| 來源刪除、改名及備份 | 把來源移到垃圾桶，重開引用筆記會看到缺少來源的提示。還原來源後再次開啟。用「檔案 → 備份工作區」另存，再在獨立資料夾以備份副本開啟。 |
| Vault 文字嵌入 | 匯入含重名筆記的合成 Vault。用 `![[資料夾/檔名]]`、`![[資料夾/檔名#標題]]` 或 `![[資料夾/檔名#^sample-1]]` 在閱讀模式顯示原文。附件、插件自訂嵌入和跨 Vault 連線維持原樣。 |
| 從月曆找日誌 | 按 F6 選「日誌月曆」。可切換月份，或輸入 `YYYY-MM` 跳月。星期一為第一欄。點已有日誌的日期會開啟原筆記，空白日期會建立日誌。垃圾桶日期需先還原才可開啟。 |

同步區塊和日誌月曆是本機操作。同步區塊共用已保存的 Markdown，日誌月格整理已存在的日期。官方資料可用於對照操作範圍。[Notion 同步區塊](https://www.notion.com/help/synced-blocks) · [Obsidian 嵌入](https://obsidian.md/help/embeds) · [Heptabase 日誌白板](https://wiki.heptabase.com/build-a-journal-calendar-whiteboard-in-heptabase)

## 第 22 版候選

先用現行版本備份，再用副本開啟候選。

| 流程 | 操作與界線 |
| --- | --- |
| 混合物件排列 | 在同一白板按 Ctrl 選取至少兩張卡或物件，選「白板操作 → 對齊或等距排列」。等距至少選三項。預覽後確認，按實際尺寸計算邊緣與間距，保留卡片和連線。需要返回時選「復原最近一次排列」。若位置或物件已變更，請重新整理白板。 |

| Vault 未連結提及 | 開啟已匯入的目標筆記，按 F6 執行「檢查 Vault 未連結提及」。可用來源筆記的完整標籤限制範圍，名稱與別名的唯一性仍以整個匯入批次核對。選取來源並確認前可看上下文。接受後只在工作區新增這一處本機連結。可用筆記版本記錄復原。 |
| 跨頁待辦總覽 | 按 F6 選「跨頁待辦總覽」。可看整個工作區、目前白板或目前筆記。選勾選狀態，再依待辦首行、標題或 Vault 路徑搜尋。選結果後可定位原始標記，或直接勾選、取消勾選。若來源在搜尋後已編輯，請重新搜尋。 |

Linux 資料層測試通過 183 項，Windows x64 測試通過 190 項。介面驗收使用同一份 EXE，在只有 loopback 的 QEMU／Wine 10 客體執行。第 21 版的 40 張原資料表逐列比對一致。

- 白板驗過混合尺寸等距、靠左對齊、重疊拒絕及重開後復原。研究 ZIP 的確切路徑含「片場 參考.png」。空工作區可匯入上一版及新版 ZIP。亦將新版解開到乾淨資料夾並解碼圖片。這輪沒有新可用的官方 Obsidian 桌面，官方顯示待驗。
- 具名檢視重開後保留本月區間，可複製群組、改為上個月並移到前面。另以鄰近日期測本週的星期一、星期日兩端。
- 以完整標籤縮小 Vault 來源，先取消再確認。僅工作區內該處建立連結，原 Vault 逐檔雜湊一致。重開可開至正確的同名筆記。
- 跨頁待辦可跳到標記並勾選。驗收另以同一 EXE 重播回匯副本情境，確認勾選原筆記時副本保持待完成。另一個資料庫連線先修改來源時，舊結果會拒絕寫入。

在合成白板放一張普通筆記、兩張尺寸不同的圖片或文字物件。先試等距，再重開復原，核對連線仍在。匯出時可用含空格的繁中圖片檔名，解開後核對 Board.canvas 的檔案節點與同批附件。離線測試應另用一份空白工作區回匯。

## 第 21 版候選

從現行版本另存備份，再以副本開啟候選。兩種貼上供給的資料格式不同，請分開操作。

| 流程 | 操作與界線 |
| --- | --- |
| 貼上像素 | 從影像程式複製合成圖片，在「白板操作」選「貼上剪貼簿圖片」。紙間讀取支援的 DIB 或 DIBV5 位元格式，另存為 PNG。 |
| 貼上檔案 | 在檔案總管複製本機 PNG 或 JPEG，回到「白板操作」選「貼上圖片檔案」。另可選「匯入本機圖片」。原檔名與檔案位元均保存。 |
| 位置、尺寸及連線 | 拖曳圖片卡移動。右鍵選「調整圖片卡大小」輸入寬與高。預覽維持原圖比例。右鍵選「與另一張卡片連線」，連到已在板上的筆記或圖片卡。 |
| 可攜 Canvas | 選「匯出研究白板與附件」。ZIP 內有 Board.canvas、原本的 Markdown 和 PNG／JPEG。複製 ZIP 到另一個位置後，從「白板操作 → 匯入研究白板與附件」建立新白板。範圍為普通筆記卡與圖片卡，包含標題、正文、原圖、尺寸及無方向連線。含分區、子白板、PDF 摘錄關係或額外附件時，程式會拒絕匯出，以免漏掉內容。另以 SQLite 備份搬移工作區屬性及原有筆記關係。 |
| 多層範本 | 集合檢視的「資料列範本」可從空白建立。編輯時選「新增範本子頁」，可指定任一現有頁作上層。可預覽階層或移除整個分支。套用範本時選擇是否建立整份子頁，各筆記使用新 ID。 |
| 相對日期 | 在具名檢視的篩選中選日期欄或日期型別公式。可設定今天、昨天或明天，也可設定前後 1 至 365 日。前後區間均排除今天，重新查詢時依本機日期計算。 |
| Vault 標籤面板 | F6 選「瀏覽 Vault 標籤」，再選匯入批次。可按名稱或筆記數排序，在樹狀和平面間切換，展開及收合全部或個別分支。可在標籤選單加入或移除搜尋詞，按交集找到原始筆記。 |

本機資料層通過 177 項測試。Astra 在只有 loopback 的 QEMU 客體用 Wine 10 驗證同一份 Windows x64 EXE。Windows 目標測試通過 184 項，介面驗收通過 12 條流程，共 121 個檢查點。第 20 版合成工作區升級後，39 張既有資料表的全部欄位與資料列均與升級前相符。

兩個貼上結果各自比對。Win32 測試工具分開提供 DIB 像素和 CF_HDROP 檔案清單，補足 Wine 中影像程式與檔案總管的格式供給。像素路徑比對全部 768 個合成像素，檔案路徑比對原 PNG 的 SHA-256。實際拖移圖片卡，右鍵調為 212×169 後連到原筆記。重開匯出，再匯入乾淨工作區，圖像、標題、附件檔名、尺寸和連線皆保留。原生 Windows 10／11 的來源程式貼上仍待驗證。

### 合成研究白板

1. 新建「研究問題」「解答」「後續問題」三張筆記卡並連起來。將「解答」原卡放入第二張白板，確認兩張板都能開啟同一篇解答。
2. 用影像程式複製一張合成色塊，使用第一個貼上入口。再從檔案總管複製另一張本機合成圖片，使用第二個入口。把兩張圖片放到不同位置，調整大小後連到解答。關閉並重開，核對位置與連線。
3. 匯出研究 ZIP。將它移到只放交付檔的資料夾，解開後檢查 Board.canvas 的檔案節點與同批路徑。再將 ZIP 匯入乾淨紙間工作區，確認兩張圖片可開啟，筆記、位置和連線仍在。

舊候選的 529 處內部路徑出現在 Rust 相依套件的唯讀資料段。GNU 交叉建置用 Rust 的前綴映射重建全部鎖定依賴，並以 C 編譯器的路徑映射涵蓋內建 SQLite。此輪已在獨立的 C 樣本驗證 `__FILE__` 可被映射。Rust 映射與 C 編譯各自生效，Windows CI 仍會直接掃描最終 EXE，通過後才可上傳產物。[Rust 路徑映射](https://doc.rust-lang.org/rustc/remap-source-paths.html) · [GCC 編譯選項](https://gcc.gnu.org/onlinedocs/gcc/Overall-Options.html)

舊 EXE 讓掃描器找出 529 處內部路徑。最終 EXE 在已知路徑、測試識別字及憑據格式的掃描中為零命中。Windows ZIP 內的 EXE 與單獨檔逐位元一致，並包含繁中說明及與上一候選相同的 238 份授權通知。原始碼 ZIP 逐檔與 Git 歸檔核對，保留供回歸測試使用的合成樣本。

最終 EXE 的 SHA-256 為 `02d23b0b2c3328b5bb799933fef4fe166362263aa0acb8337befad25366f94ce`。Linux 離線測試通過 120 項。Astra 在無網卡 Wine 10 以同一 SHA-256 及同一版 Windows 測試程式通過 125 項 Windows x64 測試，並完成三條新工作流的 11 段介面驗收。兩個白板入口在更正驗收腳本的標題比對後，以原 EXE 重驗。重複放入仍保留位置，回跳可看到相同選區且沒有重建標註。

本輪維持本機候選。原生 Windows 10／11、標準帳戶、繁中注音、SmartScreen 仍待實測。CI 的 MSVC 建置及新增的上傳前檢查也未在原生 Windows 執行。公開 repo 和 v0.1.1 未變更。

### 筆記版本差異與還原

1. 開啟筆記，在「更多 → 檢視與還原版本」選擇時間與版本號。差異視窗分列標題和正文，`−` 表示目前內容，`＋` 表示舊版內容。行號以各自版本為準，行末標出原始換行方式。空白舊版會直接提示。
2. 視窗開啟時若有未存草稿，差異會採用編輯器內的文字。關閉預覽回到草稿，保存後可重新比較並還原。與目前已保存內容完全一樣的版本只有關閉按鈕。
3. 選擇「還原此版本」才會將選取版本的完整標題及正文寫入。取消可離開比較。還原前的版本會進入歷史，之後可以再選回。選定版本若已清除，或目前保存版本在預覽後變動，請重新開啟筆記並比較。
4. 屬性、附件、子頁和版面留在目前筆記。還原若改變正文，綁定舊正文位置的螢光標記會清除。可在還原前用「檔案 → 備份工作區」保存當時的正文與標記，再用備份副本開啟查看。
5. 差異預覽可能省略長行或大範圍變更。「還原此版本」會取用完整舊版。

### 全域搜尋筆記

1. 按 Ctrl+Shift+F 或選「檔案 → 全域搜尋筆記」。輸入標題或正文片語，可加上標籤與 Vault 來源資料夾。各欄條件須同時符合。留空關鍵字時，也可只依標籤或資料夾查找。
2. `#製片` 包含 `#製片/早班` 等子層，`=#製片` 只找完全相符的標籤。資料夾填寫 Vault 相對路徑，例如 `製片/分鏡`，範圍包含其子資料夾。英文字母 A–Z 忽略大小寫，其餘字元以原字比對。
3. 選取一筆結果可預覽命中上下文，並辨識同名筆記的來源路徑。「開啟命中」會選取標題或正文的第一處命中。全域搜尋只列使用中的筆記，還原後可再找到。已移到垃圾桶、刪除或後續修改的結果需要重新搜尋。
4. 每篇最多顯示一筆，按新到舊列出，最多 100 筆。遇到搜尋上限時可縮小範圍。三個字元以上的關鍵字會用索引找候選，再核對原文。較短的詞也可搜，會逐筆比對。目前搜尋筆記標題與原始 Markdown，PDF 標註可從原有入口搜尋。

### Canvas 平移、縮放與重開

1. 從「檔案 → 匯入 JSON Canvas」開啟畫布。用滑鼠中鍵拖曳平移，游標指著要看的位置轉動滾輪即可縮放。拖曳途中按 Esc 可取消。
2. 關閉後，從「檔案 → 開啟已匯入的 Canvas」選擇同一份畫布即可接回保存的視野。每份畫布分別記錄視野，工作區備份也會保存這項設定。
3. 從「Canvas 操作 → 將畫布調整至視窗」可回到自動適應。視野操作只改變工作區檢視設定，匯出的 JSON Canvas 保留原有節點座標、連線及欄位。回到舊版程式時，請使用升級前的工作區副本。

### Canvas 框選、復原與搬移

1. 從畫布空白處按住左鍵拖出選取框。框線完全包住的節點會標示為已選取，拖其中任一節點即可一起移動。點空白處清除選取。拖曳途中可按 Esc 取消。拖節點右下角仍可單獨調整尺寸。
2. 從「Canvas 操作 → 編輯 Canvas」新增或刪除連線。要復原最近一次編輯，可使用「Canvas 操作 → 復原上一次 Canvas 修改」，也可在畫布有焦點時按 Ctrl+Z。同一工作區重開後仍可復原。整批移動算一次。每份畫布最多保存一步，工作區的復原資料有 64 MiB 上限，超出時清除最舊的紀錄。若 Vault 路徑更新改寫了同一畫布，該畫布的舊復原紀錄會失效。
3. 從「Canvas 操作」匯出 `.canvas`，再到另一個工作區用「檔案 → 匯入 JSON Canvas」開啟。匯出檔含節點、位置、連線及擴充欄位。復原紀錄由來源工作區保存。若從含附件的 Canvas ZIP 匯入，請使用「匯出 JSON Canvas ZIP」一併攜帶封裝內的附件。

## 格式與目前限制

- **PDF**：預覽最多讀取 8 MiB 的來源，每頁像素長邊最多 1,400。選區用左上角起算的頁面比例保存於紙間資料庫。紙間可在介面重顯選區，匯出的來源 PDF 保持匯入時的位元組。複雜 PDF、旋轉頁、非預設裁切框、加密及原生 Windows DPI 還要分別驗證。
- **Canvas**：可以直接拖曳或從選單輸入座標與尺寸，也能調整堆疊、建立與刪除連線、修改標籤與端點樣式。未改內容直接匯出時保留原檔；有修改時會重新序列化 JSON，並保留未改的擴充資料。已匯入的 Canvas 可綁定紙間工作區內的 Vault 副本，檔案節點可以跳到明確匹配的筆記。預覽最多畫 500 個節點及 1,000 條線。完整 Vault 雙向同步及批次遷移仍有差距。[JSON Canvas 1.0](https://jsoncanvas.org/spec/1.0/)
- **REA 與格式觀察**：REA 6.10.1 核對合成 ZIP 的前後成員，確認更改畫布幾何、疊放和連線後，只有畫布成員的雜湊變化。Poppler 在 72 與 144 DPI 都裁出預期的合成 PDF 文字，72 DPI 裁切圖和整頁對應範圍逐像素相同。[前一階段 REA 證據](REA-EVIDENCE.json)
- **Windows**：本輪介面在 Debian／Wine 10 執行，客體只見 loopback。乾淨 Windows 10／11 標準帳戶、中文 IME 和 SmartScreen 仍待實測。較早候選曾在 GitHub-hosted Windows Server 2022 測試原始碼及儲存流程。[較早原生 Windows 測試](https://github.com/yung13yubabie/paperroom/actions/runs/45291962904/job/138102699385)
