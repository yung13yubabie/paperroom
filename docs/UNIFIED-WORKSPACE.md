# 紙間的跨視圖筆記導覽

一篇筆記在工作區只有一份正文、屬性、附件及版本歷史。集合用筆記 ID 表示成員，具名關聯保存有方向的筆記 ID。JSON Canvas 用各自的節點 ID 表示位置，由已選定的 Vault 和確切路徑回到同一篇筆記。從數個入口開啟一篇筆記，會回到同一份資料。明確歸屬的匯入資料也走這些入口。

## 操作

在筆記中按 **連結**：

- **具名關聯的來源與目標**有兩個方向。選擇「指向此筆記」可回到建立關聯的來源。選擇「此筆記指向」可開啟目標。選單列出名稱、來源路徑或上一層筆記，以及筆記 ID。同名筆記可依路徑與 ID 辨認。
- **查看此筆記的原生白板位置**列出放有這篇筆記的紙間白板。選一張白板會定位並框選同一張筆記卡。卡片離開視野時會捲到位置。若所在分區已收合，會在目前視窗展開該區。雙擊卡片可返回最新筆記。右鍵選「移出白板」只移除這張白板上的放置，原筆記、附件、集合與其他白板位置仍保留。按住 Shift 滾動滑鼠滾輪可水平捲動白板。
- **查看此筆記的 Canvas 位置**先選已綁定的畫布，再選確切節點。一篇筆記在同一畫布重複出現時，兩個位置各自保留。從選到的節點可再開啟原筆記。

從 Heptabase Markdown ZIP 匯入另附的標準 JSON Canvas 時，紙間會記住這次匯入的檔案節點 ID、ZIP 根目錄下的完整 Markdown 路徑，以及對應筆記。開啟可編輯的伴隨圖，在畫布選單選「開啟同包來源筆記…」，可回到那篇筆記；從筆記的「查看此筆記的 Canvas 位置」可選回原節點。移動節點仍保留對應。從畫布選單的「新增同包筆記節點…」可以依完整 ZIP 路徑及筆記 ID 選一篇，輸入位置與尺寸。同一篇可以放在多處，每個位置都可往返原筆記。另一個入口手動輸入檔案路徑時，紙間只保存該節點的文字路徑。先前版本匯入的圖沿用當時的綁定狀態。
- **前往**和**反向連結**沿用正文解析結果，有可辨認的標題或區塊時可到原位置。原有關聯圖入口也可繼續使用。

具名關聯的傳入清單從同一筆有方向的關聯讀取，因此不會改變彙總方向。依每頁 40 條瀏覽。開啟前會核對兩端的穩定身分和該方向的關聯，若資料列已移除或筆記在垃圾桶，舊選項會被拒絕。還原筆記後關聯可重新開啟。這些操作不增加資料表或改變備份格式。

### Bases 欄位跨視圖編輯的驗收

匯入支援的 `note.status` 欄位時，可選 **固定快照** 或 **連結工作區 status（可編輯）**。兩份 Base 即使分別稱它「進度」和「狀態」，也會讀取同一篇筆記的 Markdown 頁首。從集合操作的「表格與清單欄位」選「編輯連結的 status…」，再選欄位與資料列。也能直接編輯同一篇筆記，回到集合檢視重新讀取。現行支援 `note.status == "完成"` 形式的文字相等公式。已開啟的其他視窗需重新進入檢視才會重讀。

寫回限於有明確 Vault 來源、且原本是可辨認單行文字的 `status`。同名紙間屬性與另一篇同名筆記各自保留。完整工作區備份會保存欄位綁定與正文。來源 Vault 和原始 `.base` 維持原樣。


### Bases 布林與十進位數值

當 `.base` 使用如 `note.approved == true` 或 `note.cost >= 2.5` 的比較時，紙間可依比較常值辨認來源型別。匯入時選「連結工作區欄位（可編輯）」。從集合的「表格與清單欄位」選「編輯連結的布林或數值」，可編輯頁首的布林、限定長度的十進位數或 null。支援的數值最多 15 位整數和 6 位小數。缺欄、null、false 和 0 各自顯示。來源 Vault 檔案仍可另行保留。

比較式結果在重新開啟集合或從該集合修改時重算。支援 `groupBy: {property: note.cost, direction: ASC}` 對已顯示且可辨認型別的欄位分組，數字依十進位值排列。篩選自匯入當下決定成員，後續修改會更新欄值和分組；成員資格不會重跑。其他 Bases 公式、多欄列排序或其他分組形式會明確提示不支援。 分組的收合設定與同名的紙間屬性分開保存。具名檢視可在同一集合複製。

### 伴隨畫布中的同包圖片

匯入平面 Heptabase Markdown ZIP 時，若另附的標準 Canvas 在檔案節點或群組背景寫了 `圖/場景 一.png`，紙間會從 ZIP 根目錄找完全相符的 PNG 或 JPEG。請從「檔案 → 開啟已匯入的 Canvas」開圖，從畫布選單的「儲存封裝附件」可取回原始圖片。「匯出 JSON Canvas ZIP」會將畫布放在輸出 ZIP 的根目錄，圖片保留原相對路徑。匯出的 ZIP 只帶畫布和已保存的圖片；整份工作區備份另保留同包筆記與節點之間的對應。

大小寫衝突、同名但在其他資料夾、超額或未取得的圖片會列為缺件，畫布保留原參照。每張圖片上限 8 MiB，每次交接最多 512 張、讀取 32 MiB 圖片資料；畫布預覽最多載入 24 張。匯入前已存在於工作區的畫布維持原狀。

### 從 Canvas 開啟釘選的 Bases 檢視

先匯入 Vault 的筆記和 `.base`，再將原畫布綁定同一個匯入 Vault。畫布選單的「手動配對 Bases 檔案來源」會列出釘了具名檢視的卡片。選擇卡片並核對完整檔案路徑與收據 ID。若檔案位於子目錄或同一 Vault 有多份同名收據，需選擇本機 Vault 根目錄核對原檔位元。仍有多份相符收據時會要求停止該次配對。可從畫布選單撤銷配對。

同一個檔案可在畫布有多張卡。紙間依各節點自己的 `subpath` 選擇具名檢視。從「預覽或開啟 Bases 具名檢視」可查看前十筆，或進入完整檢視編輯。原始 Canvas 檔案與匯出內容會保留原有節點欄位。

匯入時若選「動態篩選與排序（連結來源）」，整理或重開會依筆記目前的欄值更新成員。支援合取的布林和數值比較、最多四個布林或數值排序欄位。平手依相對路徑及筆記 ID 排序，候選範圍是匯入時核對的原 Vault 筆記和路徑。若來源移動，需重新匯入以納入新路徑。一般快照與既有連結模式保留原成員行為。

### 從單一 Canvas 節點另存附件

在已保存附件的檔案卡按右鍵可另存該卡的原始檔案。在群組標題或邊框按右鍵可另存該群組的背景圖。同名圖片採封存中的完整路徑各自取用。
