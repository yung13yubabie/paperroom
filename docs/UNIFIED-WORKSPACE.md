# 紙間的跨視圖筆記導覽

一篇筆記在工作區只有一份正文、屬性、附件及版本歷史。集合用筆記 ID 表示成員，具名關聯保存有方向的筆記 ID。JSON Canvas 用各自的節點 ID 表示位置，由已選定的 Vault 和確切路徑回到同一篇筆記。從數個入口開啟一篇筆記，會回到同一份資料。明確歸屬的匯入資料也走這些入口。

## 操作

在筆記中按 **連結**：

- **具名關聯的來源與目標**有兩個方向。選擇「指向此筆記」可回到建立關聯的來源。選擇「此筆記指向」可開啟目標。選單列出名稱、來源路徑或上一層筆記，以及筆記 ID。同名筆記可依路徑與 ID 辨認。
- **查看此筆記的原生白板位置**列出放有這篇筆記的紙間白板。選一張白板會定位並框選同一張筆記卡。卡片離開視野時會捲到位置。若所在分區已收合，會在目前視窗展開該區。雙擊卡片可返回最新筆記。右鍵選「移出白板」只移除這張白板上的放置，原筆記、附件、集合與其他白板位置仍保留。按住 Shift 滾動滑鼠滾輪可水平捲動白板。
- **查看此筆記的 Canvas 位置**先選已綁定的畫布，再選確切節點。一篇筆記在同一畫布重複出現時，兩個位置各自保留。從選到的節點可再開啟原筆記。
- **前往**和**反向連結**沿用正文解析結果，有可辨認的標題或區塊時可到原位置。原有關聯圖入口也可繼續使用。

具名關聯的傳入清單從同一筆有方向的關聯讀取，因此不會改變彙總方向。依每頁 40 條瀏覽。開啟前會核對兩端的穩定身分和該方向的關聯，若資料列已移除或筆記在垃圾桶，舊選項會被拒絕。還原筆記後關聯可重新開啟。這些操作不增加資料表或改變備份格式。
