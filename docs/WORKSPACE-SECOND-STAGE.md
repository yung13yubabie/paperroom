# 離線工作區第二階段

這是紙間的本機候選。資料庫升級至第 4 版，首次開啟會在單一交易建立新版資料表。升級前可在舊版選「檔案 → 備份工作區」，再以副本驗證。第 3 版以下的紙間無法開啟已升級的工作區。

| 工作流程 | 候選版操作 | 仍有差距 |
| --- | --- | --- |
| 集合看板 | 在「檔案 → 資料集合與看板」建立集合，加入既有筆記，狀態名稱形成欄位。從「看板操作」移動資料列。同一篇筆記可在不同集合有各自狀態。 | 尚無拖曳換欄、自訂欄順、多型別、自動化、行事曆或 Notion 資料庫往返。 |
| 筆記關聯及公式 | 「更多 → 筆記關聯」可保存具名稱的單向關聯並開啟目的筆記。集合公式可使用 number(prop("工時")) * 2 或 if(prop("狀態") == "完成", 1, 0)。 | 支援文字、數字、布林、基本運算、比較及條件。尚無關聯回寫、彙總、Notion 全函式或跨集合公式。 |
| JSON Canvas | 從「檔案 → 匯入 JSON Canvas」開啟畫布，由「Canvas 操作」匯出。JSON Canvas 1.0 的四類節點、順序、幾何、連線及擴充資料保存在原始檔，匯出逐位元相同。 | 唯讀預覽最多 500 個節點與 1,000 條線。極端座標及非正尺寸不繪製。檔案、網址與背景只保存參照。尚無完整畫布編輯、檔案節點內嵌及 Vault 往返。 |
| 附件與 PDF | 「更多 → 附件與 PDF 摘錄」可將 PDF、PNG、JPEG、文字及 Markdown 的原始位元組存進 SQLite，每份最多 8 MiB。可輸入 PDF 頁碼、引文及註解，附件可另存原樣副本。 | 尚無 PDF 閱讀、視覺畫線、文字擷取或 PDF 頁數驗證。第三方 Markdown 匯入不會自動匯入附件。 |
| 白板分區 | 在「白板操作」建立命名分區，右鍵卡片可指定或取消分區。邊框跟隨卡片的範圍。 | 尚無自由分區幾何、拖動整組、分區嵌套、背景或 Heptabase 白板轉換。 |

## 實際觀察

宿主 Xvfb 的 UNIX socket 曾回傳 EPERM。改用無網卡的 Debian QEMU 客體，成功以預設 Electron 沙箱及非 root 帳戶，操作官方 Obsidian 1.15.1 的合成 Vault。已看到 YAML 屬性、筆記跳轉及反向連結、Canvas 的檔案與文字節點及箭頭，也實際建立當日日誌。觀察適用於 Linux 版。

REA 6.10.1 的公開發行包與合成 ZIP 紀錄見 [REA 證據](REA-EVIDENCE.json)。REA 對單獨的合成 Canvas 與 PDF 回報格式不支援，將樣本放入 ZIP 後成功驗到容器成員。Canvas 資料語意以公開格式規格和 Obsidian 介面交叉核對，PDF 樣本另以 Poppler 確認頁數及文字。[格式研究與本機／自架方案](LOCAL-OPTIONS.md)
